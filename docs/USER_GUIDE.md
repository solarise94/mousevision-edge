# 小鼠称重 · 本地版 使用说明

适用版本：v0.3.4（离线版 / 本地版，应用名「小鼠称重·本地版」）

本应用配合 **K797 蓝牙天平** 使用：把小鼠放上秤盘，App 通过蓝牙实时读取重量并录像留证，自动记录每只小鼠的体重。离线版的所有数据**只保存在手机本机**，不需要联网、不注册账号，通过导出功能把数据取出。

---

## 一、准备工作

| 需要什么 | 说明 |
|---|---|
| K797 蓝牙天平 | 广播式蓝牙天平，量程 0–6553.5 g，读数精度 0.1 g |
| Android 手机 | Android 8.0（系统 26）及以上 |
| 存储空间 | 每箱会保存录像与照片，建议预留 1 GB 以上 |

App 需要的权限：**相机**（扫码选箱、拍摄记录视频与照片）、**蓝牙**（扫描连接天平）。Android 11 及以下系统扫描蓝牙广播时会额外请求**位置权限**，这是系统要求，App 不采集位置。

---

## 二、用什么秤：K797 蓝牙天平

- **无需配对**：K797 通过蓝牙**广播**持续播报重量，App 只"听"广播，不做蓝牙配对、也不需要输入配对码。秤开机即开始广播。
- **识别方式**：App 自动识别广播名为 `K797` 且带指定厂商数据前缀的天平，不会误连其他蓝牙设备。
- **量程与精度**：0–6553.5 g，0.1 g 分度。
- 一部手机同一时间连接一台天平；多台秤同时开机时，在连接列表中点选你要的那台即可。

> 其他型号的蓝牙天平暂不支持。支持的型号由配置文件驱动，后续新增型号无需升级也能识别（见版本更新说明）。

## 三、怎么连接天平

1. **打开天平电源**，等显示屏亮起。
2. 打开 App，首页上方有「**天平**」卡片，点右侧「**连接**」。
3. 弹出「选择天平」列表（实时扫描附近的天平），点选你的 K797。
4. 读数到达后自动完成选择，卡片状态变为「**已连接**」，屏幕上出现实时克数。

**自动恢复**：选过的天平会记在手机里，下次打开 App 自动重连，无需重复选择。

常见状态说明：

| 状态 | 含义 / 处理 |
|---|---|
| 正在搜索天平… | 正在扫描，稍候片刻 |
| 已连接 | 正常，读数实时刷新 |
| 信号中断 | 超过 15 秒没收到广播——靠近天平，或断开后重新连接 |
| 无法连接 | 天平可能没开机或电量低，开秤后重试 |

## 四、开始称重：完整流程

### 1. 开始录制
首页点「**开始录制**」。未连接天平时会提示「请先连接天平」。

### 2. 选择箱子
三种方式任选：
- **扫码**：扫描贴在箱子上的二维码，自动选箱；
- **手动输入**：点底部「手动输入」，填箱号（如 `C57-023`，支持字母/数字/`.`/`_`/`-`）；
- 扫码后如果该箱还没建立，会提示「是否新建？」，确认后补填信息即可。

箱子可以在「箱子管理」里提前建好（箱号、品系如 C57BL/6 / BALB/c、编号起始格式），建好后可多次录制，编号自动续接。

### 3. 选择记录方式（三选一）

| 方式 | 适合场景 | 操作 |
|---|---|---|
| **即时报数**（默认） | 常规称重，当场核对 | 每只放上后读数稳定会自动**锁定并语音报数**，你点「确认」记录；读数不对点「重测」 |
| **后匹配** | 追求速度，事后核对 | 连续放鼠即可，每只自动记录不停顿，事后在记录里审核 |
| **手动** | 不想用自动判定 | 看天平读数稳定后，点「记录当前重量」录入 |

### 4. 称重页操作
- 把手机架好，取景框里同时看到**秤盘**和**天平显示屏**两个区域；
- 首次进入会先**校准**（确保秤盘空载，等待即可）；
- 之后流程：放上小鼠 → （自动锁定 / 手动点录）→ **取走小鼠**等秤清零 → 放下一只；
- 每确认一只，屏幕显示「已记录 N 只」，同时抓拍一张确认瞬间的照片留证。

### 5. 完成本箱
点右上角「**完成本箱**」，停止录像并把本箱所有记录（含照片、视频）保存到本机，显示「已保存到本机 · 共 N 只」。可「查看本箱记录」或直接「继续录制下一只」。

> **意外退出不丢数据**：称重过程中每确认一只就即时存档。App 中断/闪退后重新进入，会提示「已恢复 N 只未完成记录」，可继续。

## 五、数据保存在哪、怎么导出

- **所有数据仅存本机**（设置页可查看当前记录总数）。
- 导出入口：**设置 → 导出**：
  - **导出 CSV**：表格文件（箱号、品系、序号、重量、时间等列），适合 Excel / SPSS；
  - **导出 JSON（含照片）**：完整数据含每只的确认照片，适合归档备份。
  - 视频证据保留在 App 内，暂不支持导出。
- **可选：共享数据以改善应用**（设置页开关，默认关闭）：开启后，称重记录（含照片/视频）会匿名上传到开发方服务器，仅用于改进识别算法；未联网时先排队，联网后自动补传（首页「草稿箱」可查看共享队列的待传/失败情况）。不需要此功能保持关闭即可，不影响任何使用。

**建议**：定期（如每周）导出一次 CSV/JSON 备份；更换或卸载 App 前务必先导出——卸载会清空本机数据。

## 六、常见问题

**天平连不上？**
先确认天平已开机、电量充足；手机靠近天平（1 米内）；点「断开」后重新「连接」。多台天平同时开机时，在列表中重新点选正确的那台。

**读数突然不动 / 提示信号中断？**
K797 是广播式连接，中间不要遮挡天平、避免手机离天平过远。恢复后会自动续上；称重过程中短暂中断不会丢已确认的记录。

**手动模式点「记录当前重量」没反应？**
录入有防抖规则：读数中断时稍候再点；请先放上小鼠（不能空秤录入）；录完上一只要先取走小鼠、等秤清零。

**扫箱子二维码没反应？**
光线不足可点「开灯」；二维码破损可用「相册」选图识别，或直接「手动输入」箱号。

**怎么更新 App？**
下载新版 APK 直接安装覆盖即可（同签名），本机箱子与记录数据全部保留。
